# Tessera

Панель для VPS. Делит ресурсы сервера на порции: каждое приложение живёт в своём
Docker-контейнере со своим лимитом CPU и RAM, а панель не даёт раздать больше, чем есть.

## Установка

На сервере с Ubuntu или Debian:

```bash
git clone https://github.com/excedereo/tessera.git
cd tessera
sudo bash install.sh
```

Скрипт поставит Docker и Node.js, поднимет сервис и покажет пароль. По умолчанию панель
слушает только localhost, подключаться к ней нужно через SSH-туннель, команду скрипт
напечатает. С флагом `--public` она откроется наружу, но по голому HTTP.

Обновление: `git pull && sudo bash install.sh`. Приложения и данные останутся на месте.

## Что можно запускать

| В проекте | Что произойдёт |
|---|---|
| `Dockerfile` | соберётся как есть |
| `package.json` | Node 22 |
| `requirements.txt` или `.py` | Python 3.12, запуск `main.py`, `bot.py`, `app.py` или `run.py` |
| `go.mod` | сборка Go |
| `index.html` | статика через nginx, порт приложения 80 |
| что угодно другое | указать базовый образ и команду запуска |
| готовый образ | имя вроде `redis:7-alpine` |

Источник: zip-архив, git-ссылка или образ.

## Что важно знать

- Лимиты это потолки, а не резерв. Панель считает сумму выданного, в неё входят и
  остановленные приложения. 512 МБ RAM оставлено системе
- CPU и RAM меняются на лету, без перезапуска. Смена окружения, портов и команды
  пересоздаёт контейнер
- Данные хранятся в томе, смонтированном в `/data` (папка настраивается). Всё остальное
  в контейнере пропадает при пересборке. Удаление приложения удаляет и том
- Внешний порт открывается на всех интерфейсах, и Docker обходит правила `ufw`
- Размер диска не ограничивается
- Панель имеет доступ к Docker, а значит фактически root на сервере

## Разработка

```bash
npm install
npm start
node test/e2e.mjs   # нужен запущенный Docker
```

Переменные: `TESSERA_HOST`, `TESSERA_PORT`, `TESSERA_DATA`, `TESSERA_PASSWORD`.
